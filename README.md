# แอพแจ้งเตือน "อย่าลืม"

แอพ Android แจ้งเตือนตามเวลา พร้อมพูดเตือนด้วยเสียง (TTS ภาษาไทย) และสั่น

## วิธีใช้
1. เปิดใน Android Studio
2. Build & Run ลงเครื่อง Android
3. พิมพ์ข้อความที่อยากให้เตือน เช่น "เอากุญแจ"
4. กด "เลือกเวลา" แล้วกด "ตั้งเตือน"
5. พอถึงเวลา แอพจะพูด "อย่าลืมนะ ..." + สั่น + แจ้งเตือน

ต้องอนุญาต: Notification, Exact Alarm, Vibrate
